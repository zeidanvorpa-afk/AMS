## Tech Stack
- Next.js 15.1.11
- React 19.0.0
- TypeScript
- Tailwind CSS
- Supabase (Database & Auth)

## Architecture
Frontend (React) → Next.js API Routes (Backend) → Supabase Database

## API Routes
- `/api/employees` - Employee CRUD
- `/api/attendance` - Attendance CRUD
- `/api/attendance/bulk` - Bulk attendance upsert
- `/api/dashboard/stats` - Dashboard statistics
- `/api/reports` - Reports data
